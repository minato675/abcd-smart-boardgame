# 스텔라

## 기본 목표

공개된 단어를 보고 관련 있다고 생각하는 그림 카드를 표시한 뒤, 다른 플레이어와 같은 선택을
했는지 비교해 점수를 얻는 게임이다.

## 선택

각 라운드의 단어를 기준으로 관련 있다고 생각하는 그림을 개인 보드에 표시한다.
너무 많이 고르면 위험도가 올라가고, 다른 사람과 겹치지 않으면 점수를 얻기 어렵다.

## 공개

차례대로 자신이 표시한 그림을 말한다. 같은 그림을 표시한 사람이 있으면 별 토큰을 얻고,
혼자만 표시한 그림이면 점수를 얻지 못할 수 있다.

## 주의

정확한 점수 계산은 사용 중인 스텔라 판본의 점수표를 기준으로 확인해야 한다.
